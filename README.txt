MN V2Ray VPN — Multi-page website starter
=========================================

Pages:
- index.html      Home
- plans.html      Pricing / packages
- download.html   Client download links
- setup.html      Customer setup guide
- contact.html    WhatsApp order link and email form
- privacy.html    Starter privacy notice
- assets/style.css
- assets/main.js

Before publishing:
1. Search for 94770000000 in contact.html and replace it with your WhatsApp number including country code, digits only.
2. Search for your-email@example.com in contact.html and assets/main.js; replace it with your real business email.
3. Confirm and edit sample pricing/data/validity in plans.html.
4. Review the privacy notice and service terms for your actual business.
5. Keep customer-specific VPN subscription links and QR codes private; do not place them on public pages.

Preview:
Open index.html in a browser.

Deploy:
- Netlify: drag the extracted folder into Netlify Drop.
- Vercel: create a project and deploy this folder as a static site; no build command is required.
- Any web hosting: upload the contents of this folder to the public web root (often public_html).

This is a front-end starter only. It does not include payment processing, account creation, VPN server provisioning, or an admin panel. WhatsApp is a placeholder until you update the number.
